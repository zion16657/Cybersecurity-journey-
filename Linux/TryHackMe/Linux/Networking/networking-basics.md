# Networking Basics

## What I Am Learning

Networking is the foundation of cybersecurity because computers and devices communicate through networks.

## Key Concepts

- IP Address
- MAC Address
- DNS
- DHCP
- TCP
- UDP
- HTTP
- HTTPS
- Ports
- Routers
- Firewalls

## Important Ports

| Port | Protocol | Common Use |
|------|----------|------------|
| 22 | SSH | Secure remote access |
| 53 | DNS | Domain name resolution |
| 80 | HTTP | Web traffic |
| 443 | HTTPS | Secure web traffic |

## Goal

To understand how devices communicate and how network traffic can be monitored and secured.
