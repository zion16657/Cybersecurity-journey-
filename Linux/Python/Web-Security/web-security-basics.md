Web security focuses on protecting websites and web applications from attacks and vulnerabilities.

## Key Concepts

- HTTP and HTTPS
- Cookies and Sessions
- Authentication
- Authorization
- Input Validation
- Access Control
- SQL Injection
- Cross-Site Scripting (XSS)
- Security Headers
